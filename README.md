# Правила и шаблоны проектов codebywater

GitHub применяет файлы из этого репозитория ко всем проектам [codebywater](https://github.com/codebywater), в которых нет своих таких файлов: [правила поведения](CODE_OF_CONDUCT.md), [как помочь проекту](CONTRIBUTING.md), [сообщения об уязвимостях](SECURITY.md), шаблоны issue и pull request.

These are the default community health files for all [codebywater](https://github.com/codebywater) projects.
