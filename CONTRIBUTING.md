# Как помочь проекту

Спасибо, что заглянули! В каждом проекте есть своё README: как запустить и как прогнать тесты. Если у проекта есть свой CONTRIBUTING, смотрите в него.

## С чего начать

- **Нашли ошибку** — откройте issue: что делали, что ожидали, что получилось.
- **Хотите написать код** — посмотрите задачи с меткой [`good first issue`](https://github.com/search?q=user%3Acodebywater+label%3A%22good+first+issue%22+state%3Aopen&type=issues). Перед большой правкой напишите в issue, что беретесь за неё.
- **Банк, сервис или формат не поддерживается** — откройте issue и приложите пример, заменив суммы и имена на вымышленные.

## Pull request

1. Сделайте форк и ветку от `main`.
2. Одна правка — один pull request.
3. Добавьте тест, который падает без вашей правки.
4. Прогоните тесты проекта: они же запускаются в CI.
5. В описании объясните, что и зачем меняется.

Проекты намеренно обходятся без лишних зависимостей: если новая действительно нужна, объясните почему.

## Личные данные

Не прикладывайте настоящие выписки, номера счетов и личные данные, даже свои. Заменяйте их вымышленными.

---

**In English.** Issues and pull requests are welcome in Russian or English. See each project's README for how to run tests. Keep one change per PR, add a test, avoid new dependencies, and never attach real bank statements or personal data.
