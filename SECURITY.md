# Сообщения об уязвимостях

Не описывайте уязвимости в открытых issue. Сообщите приватно: вкладка **Security → Report a vulnerability** нужного репозитория.

Укажите, что можно сделать с уязвимостью и как её воспроизвести. Поддерживается только последняя версия каждого проекта. Постараюсь ответить в течение недели.

---

**In English.** Please do not report vulnerabilities in public issues. Use **Security → Report a vulnerability** in the repository. Only the latest version of each project is supported.
