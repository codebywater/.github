# Сообщения об уязвимостях

Не описывайте уязвимости в открытых issue. Сообщите приватно:

- на вкладке **Security → Report a vulnerability** нужного репозитория;
- или на gregreshetnyak52@gmail.com.

Укажите, что можно сделать с уязвимостью и как её воспроизвести. Поддерживается только последняя версия каждого проекта. Постараюсь ответить в течение недели.

---

**In English.** Please do not report vulnerabilities in public issues. Use **Security → Report a vulnerability** in the repository or email gregreshetnyak52@gmail.com. Only the latest version of each project is supported.
